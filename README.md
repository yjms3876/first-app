# first-app

このアプリは、自分のことを紹介するためのシングルページ型の自己紹介サイトです。

## アプリの内容
- 自己紹介のタイトルとメインメッセージを表示
- 好きなことや大切にしている価値観を紹介
- 3つのカテゴリ（得意なこと・趣味・目標など）をカード形式で見せる
- シンプルで落ち着いた和風カラーのデザインで、親しみやすい印象を作る
- HTML と CSS のみで構成されており、手軽に見た目を確認できる静的サイト

## 主な用途
- 自己紹介ページとして公開する
- ポートフォリオの一部として使う
- 友人・仕事関係者に自分のことを伝えるための簡易サイトとして活用する

## 実行方法
ローカルで表示する場合は、`index.html` をブラウザで直接開くか、ローカル Web サーバーで表示してください。

例:
```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスします。
